🚖 Uber Ride Data Analysis & Insights Dashboard

📝 Overview
This project presents an interactive Power BI dashboard built using real-world Uber ride data. The goal of this analysis is to evaluate ride patterns, identify peak booking hours, examine category distributions (Business vs. Personal), analyze trip distances, and extract key operational insights to help improve transportation efficiency.


🔑 Key Features & Insights
* **Ride Trend Analysis:** Visualizes the total volume of rides across different days, time slots, and months.
* **Peak Hours Identification:** Pinpoints high-demand hours during the day to highlight rush periods.
* **Category Breakdown:** Compares Business and Personal trips in terms of ride counts and total distance covered.
* **Trip Distance & Purpose Analysis:** Tracks trip lengths, top routes, and the primary reasons/purposes for travel.
* **Interactive Filtering:** Allows users to filter data dynamically by date range, ride category, start location, and end location.


🛠️ Tools & Technologies Used
* **Power BI Desktop:** Used for data visualization, dashboard layout, and report design.
* **Power Query:** Utilized for data cleaning, handling missing values, and formatting data types.
* **DAX (Data Analysis Expressions):** Written to create custom measures for ride counts, average distances, and duration.
* **Data Source:** Uber Ride Dataset (CSV/Excel format).
